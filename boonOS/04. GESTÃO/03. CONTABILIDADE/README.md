# Apoio à contabilidade

Use `boon-contabilidade` para reunir o período, índice de documentos, relatório gerencial, conciliação e pendências que o profissional responsável precisa revisar.

O checklist vem do contexto real da pessoa/contador. O template não contém regras tributárias, escrituração, emissão fiscal ou transmissão de obrigações. `Pronto para revisão` é diferente de `revisado`, `enviado` e `obrigação cumprida`.

O registro pode ser `98. PRIVADO/FECHAMENTO-AAAA-MM.md`. Documentos completos continuam na fonte protegida, referenciados por ID. Não duplicar anexos apenas para montar o índice.
