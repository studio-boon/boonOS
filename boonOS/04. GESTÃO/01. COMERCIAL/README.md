# Comercial

Use `boon-comercial` para oportunidade e próximo passo, `boon-propostas` para a oferta revisável, `boon-precificar` para o cálculo interno e `boon-clientes` para o aceite/onboarding.

Registros reais sugeridos, criados somente quando necessários:

- `98. PRIVADO/PIPELINE.md`: oportunidades e fontes.
- `98. PRIVADO/CLIENTES.md`: identidade e relações preservadas.
- `98. PRIVADO/PRECO-ID.md`: memória interna do cálculo de preço.

A proposta e a entrega vivem no projeto, em `00. TRABALHO`, com um único ID. CRM existente pode continuar canônico; registre seu papel no contexto em vez de copiar todo o funil.
