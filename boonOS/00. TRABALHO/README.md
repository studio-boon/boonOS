# Trabalho

Uma pasta por projeto, com objetivo, responsável, prazo, fontes, estado e próximo passo. Criação e operação compartilham esse registro.

Dentro de uma entrega, use as etapas que fizerem sentido:

~~~text
01. FONTES/
02. PRODUÇÃO/
03. APROVAÇÃO/
00. PRONTOS/
~~~

Crie produção quando houver trabalho em curso e aprovação quando existir uma decisão humana correspondente. Guarde o material-fonte uma única vez; use referências em documentos gerenciais. Aprovar, entregar e publicar são ações diferentes, comprovadas no registro do projeto.

Ao encerrar, preserve resultado e aprendizados. Arquivamento ou mudança de localização deve respeitar o escopo autorizado e atualizar as referências.
