# _02. MEMORIA

O contexto que não pode morrer entre conversas.

Sem isso, cada sessão começa do zero. Com isso, o sistema lembra quem você é, o que importa e onde você estava.

---

**Use para:**
- Uma nota sobre você: quem você é, o que faz, o que está construindo agora
- Contexto de projetos importantes: o que é, onde está, o que importa saber
- Histórico de decisões e aprendizados que você não quer perder
- Informações sobre pessoas, clientes, parceiros que o sistema precisa conhecer
- O que você está aprendendo agora

**Primeiro arquivo sugerido:**

Crie `sobre-mim.md` com:
- Quem você é (profissão, área, contexto)
- O que está construindo agora
- Projetos ativos
- O que é importante saber para trabalhar com você

**Não use para:**
- Documentos recebidos de fora → `_03. DOCS/`
- Trabalho em andamento → `_00. TRABALHO/`
