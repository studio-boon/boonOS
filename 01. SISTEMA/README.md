# 01. SISTEMA

Aqui vive a forma como o seu sistema pensa e trabalha. Não é uma pasta de produção: é a fonte para decisões, contexto e regras que devem sobreviver.

## Arquivos principais

| Arquivo | Para que serve |
|---|---|
| CONTEXTO.md | versão humana do que importa sobre você e sua operação |
| PERFIL.yaml | preferências estruturadas, sem dados sensíveis |
| SKILLSET.md | skills prioritárias e por que elas existem |
| ONBOARDING.md | estado da entrevista e primeira missão |
| DECISOES.md | decisões que evitam rediscutir o mesmo assunto |
| PRIVADO.md | notas locais que não entram no Git |

O $init cria ou atualiza os quatro primeiros apenas depois de mostrar um resumo e receber confirmação.

Nunca guarde senhas, tokens, dados bancários, documentos fiscais ou informação privada de terceiros nos arquivos versionados.
