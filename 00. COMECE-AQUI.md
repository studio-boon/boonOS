# Comece aqui

Você precisa de uma pasta aberta no agente e de uma situação que valha resolver. O restante pode ser construído aos poucos.

## 1. Abra esta pasta

Use Codex ou Claude Code com acesso a arquivos locais. Se ainda não baixou o sistema, siga [Instalar](<06. GUIAS/01. INSTALAÇÃO/INSTALAR.md>) e escolha a branch `beta/2.1`.

## 2. Conte o que está acontecendo

Você pode começar assim:

> Use a skill local init para configurar este sistema comigo. Hoje eu trabalho com [sua atividade] e o que mais me atrapalha é [uma situação real].

Não precisa preencher esses campos formalmente. Conte do seu jeito. O agente deve mostrar dois caminhos: começar por uma missão ou aprofundar a configuração. Em ambos, pergunta pouco por vez e confirma o entendimento.

## 3. Escolha algo que produza resultado

| Se hoje você quer... | Pode trazer... | Vai construir... |
|---|---|---|
| criar ou comunicar melhor | uma ideia, referência ou peça existente | roteiro, direção, texto ou revisão com critérios |
| organizar o trabalho | um projeto com prazo e pendências | próximos passos, responsáveis e decisões |
| entender preço ou caixa | dados de um serviço ou lançamentos do período | cenários com premissas ou uma visão financeira conferível |
| aproveitar um aprendizado | uma referência ou um erro recorrente | síntese, prática e um ajuste para testar |

Se ainda não quiser usar seus dados, peça um exemplo fictício. Ele deve ficar identificado e separado do seu contexto real.

## 4. Confira o que o sistema entendeu

O agente apresenta um resumo: quem você é, prioridades, fontes de verdade, limites, primeira missão e o que ainda falta saber. A gravação acontece no escopo autorizado. Se você já autorizou salvar o resumo, não precisa aprovar cada arquivo novamente.

Ao pausar, peça para salvar um resumo parcial. Na próxima sessão, diga “retoma minha configuração”. Sem um resumo salvo, a retomada depende desta conversa ou de você trazer o contexto de volta.

## 5. Continue usando linguagem comum

Diga “organiza minha semana”, “revisa essa apresentação”, “me situa” ou “quero melhorar esse processo”. O agente escolhe a skill pertinente e pede apenas o que falta para trabalhar. No Codex, `$init` também é uma forma de chamar o onboarding.

As duas áreas estão no [mapa de possibilidades](<06. GUIAS/02. POSSIBILIDADES/POSSIBILIDADES.md>). Você pode combinar criação e operação sem manter dois históricos do mesmo projeto.
