## Percursos de prática

### Uma semana para olhar melhor

1. Escolha duas peças que você admira.
2. Use $taste para encontrar o princípio por trás delas.
3. Use $design para recriar o problema, não a aparência.
4. Use $design-review para comparar intenção e resultado.
5. Guarde o aprendizado em 02. MEMORIA.

### Uma ideia até uma apresentação

1. Use $grill-me para achar a pergunta ou tensão central.
2. Use $presentation para montar a sequência.
3. Use $copywriting para fazer a mensagem caber.
4. Use $design para definir a direção visual.
5. Só então produza os slides na ferramenta que preferir.

### Um pequeno case de portfolio

1. Junte briefing, papel e imagens em 00. TRABALHO.
2. Use $portfolio-case-study para separar fatos de autoelogio.
3. Use $writing-filter para tornar a narrativa mais precisa.
4. Use $design-review nas páginas ou pranchas.

## Uma regra para não travar

Não espere uma ideia perfeita ou o contexto inteiro. Escreva o que você sabe, marque o que é hipótese e escolha o menor próximo passo que produz uma evidência.
