# Atualizar o template

O seu contexto é mais importante que a versão do template. Antes de trazer mudanças novas:

1. faça commit ou backup das suas alterações;
2. leia as notas da nova versão;
3. compare AGENTS.md, docs, templates e skills;
4. aplique apenas o que fizer sentido para o seu sistema;
5. nunca substitua 01. SISTEMA, 02. MEMORIA ou 00. TRABALHO sem revisar linha por linha.

Se você criou o seu próprio repositório a partir do template, trate uma atualização como uma migração consciente, não como uma cópia automática.
