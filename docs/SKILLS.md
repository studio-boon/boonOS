# Mapa das skills

O pacote traz 20 skills complementares. Elas ensinam um processo e usam o seu contexto; não são receitas fixas nem carregam material operacional da BOON.

| Skill | Para usar quando | Entrega principal |
|---|---|---|
| $init | o sistema ainda não é seu | contexto, perfil e primeira missão |
| $overview | você perdeu a visão do todo | painel de projetos, decisões e próximos passos |
| $router | o pedido está confuso | caminho de trabalho recomendado |
| $skill-creator | um fluxo se repetiu | skill simples, testável e pessoal |
| $grill-me | uma ideia precisa amadurecer | decisões e perguntas prioritárias |
| $study-playbook | quer aprender de uma referência | síntese, prática e playbook próprio |
| $writing-filter | um texto está vago ou fora de tom | versão revisada e critérios |
| $copywriting | precisa escrever para provocar ação | mensagem, variações e teste |
| $brand-storytelling | uma marca ou projeto precisa de narrativa | decisões de mensagem preserváveis |
| $content-strategy | não sabe o que criar ao longo do tempo | pilares, temas e prioridades |
| $carrossel | uma ideia precisa virar sequência social | roteiro de slides e direção visual |
| $post-social | precisa de uma peça social única | copy, hierarquia e direção de arte |
| $design | quer criar uma peça do zero | briefing, conceito e plano de execução |
| $design-review | precisa elevar uma peça existente | crítica priorizada e próxima versão |
| $taste | quer construir repertório e critério | leitura comparativa e princípios utilizáveis |
| $image-direction | precisa decidir imagem ou gerar um briefing | direção visual, seleção ou prompt |
| $presentation | precisa explicar uma ideia em slides | narrativa, estrutura e plano de deck |
| $site-design | precisa planejar site ou interface | arquitetura, conteúdo e sistema visual |
| $interface-polish | uma interface está quase pronta | ajustes de detalhe e estados |
| $portfolio-case-study | quer contar um projeto sem inflar | case com papel, decisões e evidências |

## Como elas se combinam

~~~text
referência → $study-playbook → $taste → $design
ideia → $grill-me → $brand-storytelling → $copywriting
conteúdo → $content-strategy → $carrossel ou $post-social
projeto → $design / $site-design → $design-review → $portfolio-case-study
ideia complexa → $presentation → revisão → entrega
~~~

Use $router quando não souber onde começar.
