# Gestão

A área Operacional organiza trabalho, relações, compromissos e decisões. A área Criativa usa o mesmo contexto e os mesmos projetos em `00. TRABALHO`.

| Área | O que fica aqui | Primeiro uso |
|---|---|---|
| [Comercial](<01. COMERCIAL/README.md>) | oportunidades, relações e referências de propostas | organizar uma negociação |
| [Financeiro](<02. FINANCEIRO/README.md>) | livro gerencial e visões de caixa | entender entradas e saídas |
| [Contabilidade](<03. CONTABILIDADE/README.md>) | índice mensal e pendências para revisão profissional | preparar documentos |
| [Rotina e time](<04. ROTINA E TIME/README.md>) | capacidade, semana e reuniões gerais | escolher o que cabe agora |
| [Fornecedores](<05. FORNECEDORES/README.md>) | cotações, decisões e compromissos | comparar uma compra/contratação |

Os modelos estão na [biblioteca operacional](<../05. BIBLIOTECA/02. OPERACIONAL/README.md>). Comece por uma missão, sem preencher todos os módulos. O [exemplo fictício](<../06. GUIAS/03. EXEMPLOS/OPERACAO.md>) percorre o ciclo.

Esta pasta chega sem registros reais. Dados pessoais, valores de clientes, comprovantes e documentos contábeis devem ficar em `98. PRIVADO` ou na fonte protegida autorizada. A regra de Git ignora a pasta por nome; isso não cria um cofre nem remove dados já publicados. Índices públicos também precisam omitir informações sensíveis.

Uma fonte por registro: o projeto aponta para obrigações financeiras, a proposta aponta para oportunidade e o relatório aponta para o livro. Não manter planilhas, arquivos e CRM concorrentes sem decidir qual é canônico.
