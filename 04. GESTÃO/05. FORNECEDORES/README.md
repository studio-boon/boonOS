# Fornecedores

Use `boon-fornecedores` para comparar propostas equivalentes, registrar escolha autorizada e acompanhar entrega. Obrigações confirmadas entram no livro por ID; este cadastro não replica os lançamentos.

Quando necessário, crie `98. PRIVADO/FORNECEDORES.md` com identificação, fontes, condições, responsável e pendências. Dados bancários e documentos privados permanecem no local protegido autorizado.

Uma cotação não é contratação. Entrega aceita não é pagamento. O pacote base não executa compras, transferências ou contratos externos.
