# _01. SISTEMA

As regras, decisões e padrões do seu OS.

Não é onde você trabalha. É onde você define como trabalha.

---

**Use para:**
- Registrar decisões importantes com o raciocínio por trás
- Documentar padrões que você adotou ("sempre faço X quando Y")
- Guardar a lógica do seu sistema quando ele mudar
- Anotar o que não funciona para não repetir

**Formato sugerido para decisões:**

```
## [Decisão]
Data: 
Contexto: 
Decisão: 
Por quê: 
```

**Não use para:**
- Trabalho em andamento → `_00. TRABALHO/`
- Contexto sobre você → `_02. MEMORIA/`
