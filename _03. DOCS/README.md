# _03. DOCS

Documentos recebidos ou criados para referência.

Material que vem de fora ou que você precisa guardar como registro formal.

---

**Use para:**
- Contratos, propostas, orçamentos
- Briefings recebidos de clientes ou parceiros
- Referências e materiais de pesquisa
- Notas de aulas, cursos, leituras
- Qualquer coisa que precise existir como documento

**Não use para:**
- Trabalho ativo em andamento → `_00. TRABALHO/`
- Versões antigas de documentos → `_99. OLD/`
