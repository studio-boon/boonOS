# _00. TRABALHO

O que está em andamento.

Projetos ativos, entregas abertas, ideias que estão rolando, coisas que você está fazendo agora.

---

**Use para:**
- Criar uma subpasta por projeto ou área ativa
- Guardar notas brutas de reuniões, sessões de trabalho, ideias soltas
- Manter o rascunho de entregas em construção

**Não use para:**
- Arquivos históricos ou versões antigas → `_99. OLD/`
- Contexto sobre você ou seus projetos → `_02. MEMORIA/`
- Documentos recebidos de fora → `_03. DOCS/`
