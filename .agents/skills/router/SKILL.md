# router — encontre o próximo caminho, não uma resposta genérica

## Primeiro

Leia 01. SISTEMA/SKILLSET.md e, se necessário, 01. SISTEMA/CONTEXTO.md. Se o onboarding não estiver ativo, priorize $init.

## Classifique o pedido

| Se a pessoa precisa... | Rota principal |
|---|---|
| entender uma referência e praticar | $study-playbook |
| amadurecer uma ideia ou decisão | $grill-me |
| criar uma peça ou conceito | $design |
| criticar uma peça existente | $design-review |
| construir repertório e critério | $taste |
| escrever uma mensagem ou texto | $writing-filter ou $copywriting |
| construir história de marca | $brand-storytelling |
| planejar uma linha de conteúdo | $content-strategy |
| criar peça social | $carrossel ou $post-social |
| decidir imagem ou prompt | $image-direction |
| explicar algo em slides | $presentation |
| planejar site ou interface | $site-design ou $interface-polish |
| organizar um case | $portfolio-case-study |
| olhar o estado do sistema | $overview |

## Resposta

Entregue no máximo:

1. skill recomendada;
2. motivo em uma frase;
3. o que a pessoa precisa trazer;
4. o primeiro passo.

Se o pedido combinar duas ou mais rotas, mostre uma sequência curta. Não transforme uma pergunta simples em um fluxo de cinco skills.
