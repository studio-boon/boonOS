# router — da intenção ao próximo passo

Leia `01. SISTEMA/SKILLSET.md` e o contexto pertinente. Consulte `01. SISTEMA/CATALOGO.json` para entradas, saídas e dependências. Uma instalação incompleta pode seguir com uma missão concreta; use `init` quando for necessário descobrir ou retomar contexto.

| Intenção | Caminho principal |
|---|---|
| escrever ou revisar voz | `copywriting` ou `writing-filter` |
| construir mensagem de marca | `brand-storytelling` |
| criar ou avaliar uma peça | `design` ou `design-review` |
| estudar critério visual ou imagem | `taste` ou `image-direction` |
| conteúdo recorrente ou peça social | `content-strategy`, `carrossel` ou `post-social` |
| apresentação, site, interface ou case | `presentation`, `site-design`, `interface-polish` ou `portfolio-case-study` |
| projeto, semana ou reunião | `boon-projetos`, `boon-rotina` ou `boon-reunioes` |
| oportunidade ou entrada de cliente | `boon-comercial` ou `boon-clientes` |
| escopo comercial e preço | `boon-propostas` ou `boon-precificar` |
| registrar receber/pagar | `boon-contas` |
| entender caixa e projeções | `boon-financeiro` |
| comparar registros e extrato fornecido | `boon-conciliar` |
| organizar fechamento para contador | `boon-contabilidade` |
| avaliar carga, margem ou dependência | `boon-saude-operacional` |
| cotação ou documentos | `boon-fornecedores` ou `boon-documentos` |
| amadurecer uma ideia | `grill-me` |
| estudar ou guardar aprendizado | `study-playbook` ou `boon-memoria` |
| melhorar um processo do sistema | `boon-melhorar-sistema` |
| criar, avaliar ou manter skill | `skill-creator`, `boon-avaliar-skills` ou `boon-gerir-skills` |
| conectar ferramenta ou planejar recorrência | `boon-integracoes` ou `boon-automacoes` |
| configurar ou retomar o panorama | `init` ou `overview` |

Escolha a menor rota que resolve o pedido. Diga o resultado, por que essa rota ajuda e o que falta trazer. Se houver dados suficientes e autorização, execute a próxima etapa; não encerre apenas recomendando um comando.

Um pedido pode precisar de duas capacidades, mas não apresente uma cadeia por hábito. Calcular um cenário local, registrar recebimento confirmado e executar um pagamento são ações diferentes. Preparar conteúdo também não autoriza publicar. Preserve as permissões vigentes e confira dependências antes de prometer uma saída.
